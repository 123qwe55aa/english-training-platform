# 教师后台使用指南

在站点后台登录。编辑操作需要教师 staff 账号。

## 添加学生

1. 在「学生」添加姓名，填写学习目标、上课时间、计划课堂次数及计划小课数。
2. 选择分配给他的「课程」。课程素材可以供多个学生共用，课堂完成状态、录像、徽章和奖励分别记录。
3. 设置奖励名称、每日目标、低电量阈值，以及每次完成视频／对话的奖励值。奖励名称留空会自动使用「姓名 值」。低电量阈值不能超过每日目标的一半。
4. 勾选公开后保存，使用列表中的「打开页面」发送学生专属链接。学生无需登录；所有已公开学生页面均可被其他访客访问。

已有课堂的所属学生不能直接更换，避免带走原学生的录像与学习记录。

## 添加教材

1. 在「课程」新建课程；在「课程小课」添加该课程的各个 Lesson。
2. 在小课下面的「教材内容块」按顺序添加文字／Script、MP4 视频、音频、图片／绘本页、PDF、对话或选择题；也可以从独立「教材内容块」入口添加。
3. 文字直接输入；选择题选项每行一个，正确答案填写序号（从 1 开始）。图片可用多个内容块组成绘本。
4. 上传文件并勾选内容块、小课、课程的公开状态。把课程分配给学生后，学生「我的课堂」中的课程素材库会显示教材。

视频接受 H.264/AAC MP4，单文件最多 2GB；音频接受 MP3/M4A/OGG；图片接受 JPG/PNG/WebP；PDF 须完整、可解析、未加密。除视频外单文件最多 100MB。PDF 在单独标签页打开，其余媒体可在平台内播放或显示。不支持任意 HTML、SVG 或外站视频嵌入。

VOA Lesson 1–12 保留现有专用播放器、Script 和官方 Quiz，后续新增内容块可附在原课文后。

## 设置进度

在「每日课堂」选择学生、关联小课，填写日期、课前回顾、表达卡、练习、B 方案及课后检查；授课后把状态改为「已授课」。进度页按各学生自己的计划分母计算已完成课堂／小课，单纯打开页面和播放视频不会改变授课进度。

为同样学习 VOA 的新学生，先在其档案中分配 VOA 课程，再在学生列表勾选该学生，执行「复制默认学生的课堂安排」。仅复制安排与教案；不复制已完成状态、授课日期、教师复盘、证据、录像或徽章。已有课堂不会被覆盖。

## 配置与发放奖励

- 学生档案控制每次视频／对话奖励、每日目标和名称；进度条按目标显示比例，超过目标持续充能，低于阈值显示不足，满一半显示一半。
- 在「教师发奖记录」或学生档案内填写日期、公开理由及分值。正数发奖，负数更正；记录计入所填日期，页面每 30 秒读取一次更新。
- 视频需实际观看至少 90% 并播到结尾；对话由学生确认完成。同一任务按北京时间每天奖励一次，弹出祝贺提示。
- **自动活动奖励保存在当前设备浏览器，各学生独立。教师发奖和课程进度保存在服务器。** 暂无学生登录，自动奖励不会跨设备同步，清除浏览器数据会清除其自动奖励。旧版浏览器奖励仅对默认学生迁入新命名空间。
- 录像发布仍须确认学习者同意；教师复盘与掌握证据不公开。对话完成属于自评，平台暂不评判口语质量。

## 保留与备份

每位学生使用稳定的专属页面链接（`/s/<slug>/`）。备份时应同时覆盖 SQLite 数据库与上传媒体，并在恢复后核对记录和媒体可用性。

后台公开开关决定学生材料与媒体是否可访问。所有编辑仍需教师登录。数据库与上传文件一起备份，恢复检查涵盖新增的教材文件。

## 使用 Codex 操作

可在 Codex 中使用 `$english-teaching-platform`，直接请求管理学生、导入教材、准备课堂、记录授课与发奖。工具先预览再提交，并在后台「Agent 操作记录」保留修改前后内容；无需手动重复填写后台表单。详见 [Codex 操作指南](agent-tools.md)。
