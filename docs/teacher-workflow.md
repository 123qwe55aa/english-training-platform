# Teacher workflow

1. Sign in at `/admin/` using a Django staff account. Create a learner profile and configure their plan, reward label, daily target and activity values.
2. Create or select a course, add lessons, then attach content blocks such as text, video, audio, images, PDFs, dialogues or quizzes.
3. Assign courses to a learner. Publish only content intended to be publicly readable; student pages do not require login.
4. Prepare dated sessions with review, goals, timed activities, a reduced-load option and an exit check. Record progress only after the teacher confirms the class took place.
5. Keep teacher reflection and evidence private. Publish a recording only when the learner has agreed to it.

Lesson progress is teacher-recorded. Merely visiting a page or playing a video does not complete a class. Browser activity rewards are device-local; teacher awards and progress are stored in the database.
